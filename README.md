# Project MUSE — Alpha 0.2 웹 프로토타입

J-POP / 애니송 / 보컬로이드 / 게임 OST 전문 개인화 음악 추천 **실행 가능한 시제품**.

## 가장 쉬운 실행 방법

- **`MUSE_Offline_Demo.html`** 파일을 Chrome/Edge 등의 브라우저로 열면 됩니다. 다른 파일이나 패키지 설치가 필요 없는 단일 파일 버전입니다.
- 유튜브의 음악 검색 링크는 인터넷 접속이 필요합니다. **자체 음원 재생 기능은 없습니다.**

## 개발용 실행

필수: Node.js 20+ (`npm test`), Python 3 (`npm start`).

```bash
npm start
# 브라우저에서 http://localhost:4173 방문
```

Next.js가 아닌 **의존성 없는 HTML/CSS/ES modules**로 만든 시제품입니다. 이전 Alpha 0.1의 TypeScript 추천 엔진 컴파일 결과(`engine/dist`)를 그대로 연동했습니다.

## 구현 기능

- 초기 곡 선택: 5~10곡, 검색/분류 필터, 한국어·일본어·영어 별칭
- 추가 취향 테스트: 이전 평가를 반영하는 10문항, '모름/보류' 별도
- 추천 엔진: 특징/장르 유사도 기반 10곡, 동일 아티스트 최대 2곡, 평가한 곡 제외
- 취향 프로필: 음악 특징 6개 및 선호 장르 시각화
- 추천 피드백: 좋음/별로 반영 후 즉시 다시 추천
- 저장: 브라우저 `localStorage` 시도; 스토리지가 금지된 환경에서는 현재 탭에서만 동작
- 모바일·데스크톱 대응, 키보드 포커스 표시

## 테스트

```bash
npm test
# 18개 Node 테스트
```

추가로 Chromium 인메모리 테스트에서 모바일/데스크톱의 5곡 선택 → 10문항 평가 → 추천 10곡 표시 → 피드백 후 재추천을 확인했습니다. 이 환경에서는 Chromium이 로컬 URL을 차단해 **서버 URL 직접 접속 테스트와 저장 후 새로고침 테스트는 실행하지 못했습니다.**

## 현재 제한 및 정확성 고지

1. 음악 목록 **52곡**의 제목·아티스트·분류는 개발용으로 사람이 선별해 작성했습니다. 공식 음원 DB와 일괄 대조는 아직 수행하지 않았습니다.
2. `features` 수치는 **템플릿으로 입력한 임시 주관적 분류값**이며 실제 오디오 신호 분석 결과가 아닙니다. 비슷한 스타일의 곡은 같은 값을 공유할 수 있습니다. 따라서 추천 지수는 **실제 취향 적중 확률이 아닙니다.**
3. 음악 API, 계정·Supabase, 서버 엔드포인트, 임베디드 음악 플레이어, 실사용자 정확도 측정은 **미구현**입니다.
4. `docs/001_initial.sql`은 Alpha 0.1에서 이관한 **미실행 스키마 초안**입니다. 데이터베이스에 적용했다고 주장하지 않습니다.
5. 곡 듣기 버튼은 유튜브에서 곡명/아티스트를 검색하는 링크로 이동합니다. 특정 공식 음원/영상의 재생을 보장하지 않습니다.
6. 장기 운영·상업적 서비스는 외부 API 이용 약관, 데이터 정확성 및 저작권 별도 검토가 필요합니다.

3. 필요한 시점에 Next.js + Supabase로 이전. 외부 API는 서버에서만 호출하고 사용량/라이선스 준수.
